# OneByOne CX

Descompacte todo o ZIP para uma pasta nova. Abra o index.html dessa pasta no Chrome ou no Edge.

A página inicial tem o vídeo, o logótipo, a fotografia e as imagens dos serviços incorporados no HTML. Mantenha a pasta assets junto do index.html para carregar os scripts, os tipos de letra e os recursos das restantes páginas. Mantenha também as pastas fr, pt e es.

Para publicar no repositório Onebyonecx, carregue todo o conteúdo extraído, mantendo as pastas. A origem do GitHub Pages é main / (root).
